# CRSFinder

QGIS Plugin to find CRS of a layer of which CRS is unknown.

![](./imgs/icon.png)

## Features

- By selecting CRS and applying to a layer with unknown CRS, you can check if the layer fits well to the base map.
- If correct CRS is found, you can overwrite the layer's CRS with the found one.

## Usage

- Add the layer of which CRS is unknown to QGIS.
- Open CRSFinder dock widget from the plugin toolbar.
- Select the layer from the combo box.
- Select candidate CRS from pull-down menu.
- If you find appropriate CRS, click "Apply to Layer CRS" button to overwrite the layer's CRS.
